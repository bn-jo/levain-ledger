# Levain Ledger

A sourdough bread workbench that runs in the browser, in English and Hebrew.

- **Formula**: baker's percentage calculator. Counts the flour and water in the levain, so hydration is the real dough hydration. Comes with starter recipes and a checker for recipes you find.
- **My recipes**: save formulas with notes (stored in your browser).
- **Levain build**: grams and expected peak time for any feeding ratio.
- **Water temp**: mixing water temperature for a target dough temperature.
- **Bake schedule**: a full timeline from feeding to slicing.
- **Troubleshoot** and **Method**: common problems and the full process.

It is a single static `index.html` with no build step.
